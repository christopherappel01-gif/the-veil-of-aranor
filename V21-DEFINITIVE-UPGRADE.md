# The Veil of Aranor — V21 Definitive Presentation Upgrade

## What was upgraded

### 1) Bespoke visual coverage
Additional scene art has been assigned across more of the campaign, especially for:
- wreck / camp / shore moments
- wolf / troll / marsh sections
- goblin / Order / prison / archive content
- gorge / canyon / mountain / mirror vault content
- Heart and White City endgame scenes

### 2) Audio cues
A lightweight audio cue pack has been added in `public/assets/audio/` for:
- select
- roll
- discovery
- ambush
- battle
- magic
- dialogue
- success / fail
- storm / troll

The game now attempts to play those files first, with the previous synthesised cues acting as fallback.

### 3) UI / popup polish
Challenge panels, selection controls and modal presentation have been visually upgraded to better match the fantasy tone of the game.

### 4) Journey map presentation
The map now uses an illustrated parchment backdrop to strengthen the sense of travel and world identity.

### 5) Landing page presentation
The opening page now uses brighter key art for a more striking first impression.

## Packaging note
This build is larger and includes more assets than earlier file-count-constrained builds. That is intentional.
