# V22 Ambient Motion (phase 1)

- Approved moving-sea MP4 incorporated for landing and opening voyage.
- Dynamic, low-opacity mist, light and particle layers for storm, coast, ruins, marsh, settlement, and magical scenes.
- Map fog and active markers animate subtly.
- Motion setting cycles Off → Standard → Enhanced, saved on each device.
- Respects reduced-motion preferences by default.
- Original scene artwork, game logic and multiplayer rules are unchanged.

**Important:** Only the opening sea uses actual animated source imagery in this phase. Other listed scenes use lightweight procedural CSS layers above their still images, not full image-to-video motion; this is intentionally conservative for performance.

**Tests performed:** JavaScript syntax, ZIP integrity, asset existence, full/batch file accounting. Live browser and multiplayer testing outstanding.
