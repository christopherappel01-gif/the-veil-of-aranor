# V21.4 visual mapping audit

Reviewed 147 scene IDs against their actual story contexts, including opening, alternate routes, split routes, combat and endings. All mapped files exist in the package.

The Captain's Count now uses storm-at-sea artwork, not post-wreck shoreline artwork.

The final registry is applied after older mapping sections so it is authoritative. Image reuse remains where a location is shared between adjacent beats. This is a mapping audit, not a promise of one unique image per scene.

See `V21_4_SCENE_IMAGE_AUDIT.csv` for every scene and its image.
